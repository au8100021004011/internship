# CodeOrbitTech – Data Science Internship

## Project 2: Exploratory Data Analysis (EDA)

### Objective
To perform Exploratory Data Analysis (EDA) on a sample dataset using Python libraries such as Pandas, Matplotlib and Seaborn.

### Tasks Performed

1. Performed EDA on a sample dataset using Pandas.
2. Created visualizations using Matplotlib and Seaborn:
   - Histograms
   - Bar charts
   - Scatter plots
3. Identified patterns, trends and outliers in the dataset.
4. Summarized key findings in a short write-up.

### Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

### Project Outcome
Developed practical experience in data exploration, visualization and identifying meaningful insights from data.
