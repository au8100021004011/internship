# CodeOrbitTech – Data Science Internship

## Project 1: Data Cleaning and Exploration with Pandas

### Objective
To perform data cleaning and basic data exploration using Python Pandas on a sample dataset.

### Tasks Performed

1. Loaded a sample dataset using Pandas.
2. Identified and handled missing values.
3. Detected and removed duplicate records.
4. Identified and corrected incorrect data types.
5. Calculated basic statistical measures such as:
   - Mean
   - Median
   - Value Counts
6. Summarized the data cleaning process and observations.

### Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy

### Project Outcome
Gained practical experience in data cleaning, handling missing values, removing duplicates, correcting data types and performing basic statistical analysis.
